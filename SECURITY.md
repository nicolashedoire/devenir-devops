# Sécurité du compagnon pédagogique

TaskBoard est actuellement un laboratoire local sans authentification utilisateur. Les services fournis écoutent sur la boucle locale. Les identifiants présents dans Compose sont publics et réservés à cet exercice. Les étapes de sécurité et d’exposition publique du parcours restent à réaliser.

Pour signaler un problème de sécurité, utiliser le signalement privé de vulnérabilité du dépôt lorsque cette fonction est activée. Les difficultés ordinaires d’atelier peuvent être signalées dans les issues. Retirer les secrets, sauvegardes et données personnelles des exemples.

Les tests automatisés concernent la version courante de préparation. Le registre docs/validation.md décrit précisément les vérifications réalisées et leurs limites.
